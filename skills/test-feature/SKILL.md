仅在用户原话命中下列口令之一时加载本技能：「测这个功能」「按我的要求测」「按指定方式测」。
未命中一律不加载。若不确定，按未命中处理。
</EXTREMELY-IMPORTANT>

# Test Feature

## 触发

用户要求按自己的标准测试项目里某个功能点时加载。

## 开跑前三项

必须同时具备，缺的向用户要，不要自己补：

1. 功能点：页面、命令、接口或函数。
2. 通过标准。
3. 怎么跑：命令、地址或步骤。

缺任一项就问，然后停下。不启动用户没指定的服务，不改用另一种测法。

## 跑测

三项齐了之后，严格按给出的方式跑。

失败只报告，不修。修复动作需要走 `explain-before-change`，由用户自行决定是否点名。

## 报告五项

1. 测了什么
2. 怎么跑的
3. 实际结果
4. 对照标准：通过或不通过
5. 证据：命令输出、报错或关键步骤

环境起不来、命令在进入功能前就失败：结论写「受阻」，并附上失败证据。不更换跑法。
